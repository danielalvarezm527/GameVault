# GameVault – Tienda de Videojuegos

**Estudiante:** Daniel Alvarez Moncada
**Asignatura:** Desarrollo Móvil

---

## Descripción

GameVault es una aplicación móvil de catálogo para una tienda de videojuegos. Permite explorar el catálogo disponible, consultar el detalle de cada título, agregar nuevos juegos mediante un formulario y acceder a una sección de noticias gaming con actualización automática.

---

## Tecnologías utilizadas

- React Native
- React 19.2.3
- React Navigation (Stack + Bottom Tabs)
- JavaScript / React Hooks
- react-native-safe-area-context

---

## Instalación y ejecución

### 1. Clonar el repositorio

```sh
git clone https://github.com/danielalvarezm527/GameVault
cd GameVault
```

### 2. Instalar dependencias

```sh
npm install
```

### 3. Instalar pods (solo iOS)

```sh
cd ios && pod install && cd ..
```

### 4. Ejecutar la app

**iOS:**
```sh
npx react-native run-ios
```

**Android:**
```sh
npx react-native run-android
```
